# Atividade: Estruturas em TypeScript

Aluno(a): Maggio Henrique Valente Lôbo  
Disciplina: Programação Web

## Exercícios

1. Situação do aluno no semestre
2. Conta de luz
3. Simulador de parcelamento
4. Meta de economia
5. Caixa do mercado

## Como executar

1. Abra esta pasta no VS Code.
2. No terminal integrado, execute `tsc --watch` para compilar os arquivos TypeScript.
3. Abra o `index.html` da raiz com a extensão Live Server.
4. Acesse os exercícios pelos links da página inicial.

O site será publicado em: https://Maggio128.github.io/pweb-ts-estruturas/
